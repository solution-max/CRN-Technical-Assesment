# CRN-Technical-Assesment
A RESTful Product Management API built using ASP.NET Core Web API (.NET 8), Entity Framework Core, and SQL Server. Implements CRUD operations using Repository Pattern, Service Layer, DTOs, Dependency Injection, Swagger/OpenAPI, and Clean Architecture principles.

- ASP.NET Core Web API (.NET 8)
- SQL Server & Entity Framework Core
- CRUD Operations
- Repository Pattern
- Service Layer
- DTOs
- Dependency Injection
- Swagger/OpenAPI
- Clean Architecture
